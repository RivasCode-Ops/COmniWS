# Omni Command Surface (OCS) — Design System v1

**Fase 11 UI** — implementado no renderer.

## Shell

- Sidebar 200px · Topbar 48px · Painel 360px · Canvas central com grid
- Tokens: `src/renderer/styles/omni-tokens.css`

## Node-cards

5 categorias: ferramenta, fluxo, contexto, ambiente, inteligência.

Componente: `OperacionalNode.tsx`

## Navegação

| Sidebar | View |
|---------|------|
| Hoje | Grid operacional completo |
| Foco | Timer hero |
| Tarefas | Lista Linear-style |
| Notas | Widget notas |
| Ferramentas | Grid apps |
| Ambiente | Inventário winget |
| Config | Ações sistema |

## Atalhos

- `Ctrl+K` — paleta de comandos
- `Ctrl+Shift+1/2/3` — modos FOCO/FLEX/APRENDIZADO
- `Ctrl+Shift+P` — propostas
